# Step 13 — SOC Incident Case / Report

The project contains two analyst-style incident records under `incidents/`.

Each case follows:

- alert summary
- affected asset
- observed evidence
- investigation
- MITRE context
- analyst assessment
- recommended response
- evidence references

Cases:

- `IR-001-authentication-failure.md`
- `IR-002-fim-file-modification.md`

The records are based on captured telemetry and do not claim compromise where the evidence only demonstrates a detection.
