# Step 15 — Final Portfolio Project

## Portfolio summary

This project demonstrates an end-to-end Wazuh SOC workflow on a controlled Windows environment:

- Windows security event generation
- Wazuh agent/manager telemetry ingestion
- Event ID 4625 authentication failure detection
- Alert investigation
- MITRE ATT&CK contextualization
- FIM configuration and investigation
- Process creation monitoring
- Suspicious PowerShell detection design
- Brute-force correlation concept
- Incident case documentation
- Evidence preservation and GitHub reporting

The emphasis is on demonstrating how a SOC analyst works an alert, not merely how to install Wazuh.
